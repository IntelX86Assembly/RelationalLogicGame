    How the relations behave

    Closed world. A statement holds only if a premise states it or the relation's properties force it. Anything else is false. Each phrase is its own relation, so “is the same type as” tells you nothing about “is the same size as”.

    Equivalence

    • Reflexive: aRa
    • Symmetric: aRb ⇒ bRa
    • Transitive: aRb, bRc ⇒ aRc

    Symmetric

    • Symmetric: aRb ⇒ bRa
    • Excludes self: aRa is false
    • Not transitive: aRb, bRc says nothing about aRc

    Strict order

    • Irreflexive: aRa is false
    • Asymmetric: aRb ⇒ ¬bRa
    • Transitive: aRb, bRc ⇒ aRc
    • Converse: “a is less than b” means “b is more than a”

    Connectives

    • p ⊕ q exactly one is true
    • p → q false only when p is true and q is false
    • p ↔ q both have the same value
